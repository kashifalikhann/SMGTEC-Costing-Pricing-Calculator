📖 User Manual & Reference

This guide walks through every field, abbreviation, and calculation in the SMGTEC CPQ Engine from top to bottom. Use it to understand how each input affects pricing, margins, and compliance.

1 What Is This Tool?

The SMGTEC CPQ Engine (Configure-Price-Quote) is an internal tool for generating managed IT service proposals. It takes your client's infrastructure requirements, selects the appropriate service tier, applies SMGTEC's sourcing costs and retail pricing, and produces a professional PDF quote ready to send. All costs come from the internal sourcing database and can be overridden per quote. The engine enforces compliance (RGPD/LOPDGDD, NIS2), calculates IVA (Spanish VAT), deposit requirements, and margin thresholds.

2 Header Bar

Labor Rate
Shows the current wholesale (SMGTEC's cost) and retail (what the client pays) per-hour rates for engineering labour. These are managed in the Admin DB panel. Values shown: wholesale €/hr / retail €/hr.
Admin DB Button
Opens the sourcing database sidebar. Password-protected (smg2024 by default, changeable in the panel). Use this to edit labour rates, hardware costs, and software license costs/retail prices that feed into all calculations.
PDF Quote Button
Generates a professional multi-page PDF proposal with client info, tiered pricing, terms and conditions, compliance details, and approval status. Requires jsPDF and jsPDF-AutoTable (loaded from CDN).
Manual Button
Scrolls to this user manual. Always available at the top of the page.

3 Client Information

Client Name / Company
Full legal name of the client company. Appears on the PDF quote header.
NIF / CIF
Spanish tax identification number. NIF (Número de Identificación Fiscal) for individuals, CIF (Código de Identificación Fiscal) for companies. Required for all invoicing in Spain.
Quote Date
Date the quote is prepared. Defaults to today's date. The PDF shows this and prices are valid 30 days from this date.
Email / Phone / Address
Client contact details used for correspondence and included in the PDF proposal footer.

4 Action Bar

💾 Save Proposal
Saves the entire current state (all inputs, overrides, selected tier, etc.) to the browser's localStorage. Data persists across sessions on the same device/browser.
📂 Load Proposal
Restores a previously saved proposal from localStorage. Prompts for confirmation before overwriting the current state.
📥 Export JSON
Downloads the full proposal state as a .json file. Useful for archiving, sharing between team members, or importing into other systems.
🔗 Share Link
Encodes the entire proposal state into the URL hash and copies the link to clipboard. Anyone opening this link will see the exact quote. Limit: very large proposals may exceed URL length limits.
↺ Reset Items
Resets all line-item overrides and custom additions back to defaults. Does not reset client info or input parameters.
Approval Badge
Shows ✓ APPROVED when all enabled tiers meet the margin threshold (services margin ≥ 40%), or ⚠ PENDING when any tier's services margin falls below 40%. The badge toggles dynamically as you adjust inputs.

5 Left Column — Input Cards

5A. Client Infrastructure

Desktop Workstations
Number of physical desktop PCs at the client site. Affects per-workstation software licensing costs (Backblaze, ESET, SentinelOne, N-Central) and support labour hours.
Laptop Workstations
Number of laptops. Treated identically to desktops for licensing and support — the tool adds both together as W (total workstations).
Server Assessment
Buy New Server — Recommends a Dell PowerEdge server (T150 for ≤15 users, T360 for 16+) with full warranty and Datto Siris backup appliance. Higher setup, full margin.
Retain Existing Server — Client keeps their current server. Adds Datto Siris backup only. Lower setup but may carry warranty risks.
Cloud Transition — No on-prem server. All services are cloud-delivered. Lowest setup cost, minimal hardware margin.
Expired Warranty
Check this if the client's existing hardware is out of warranty or EOL (End of Life). Triggers a warning banner recommending refresh or ProSupport extension.
Override Server Count
Manually specify the number of physical servers if the auto-detection from workstation count is incorrect.
Existing Workstations
Number of workstations already covered under a different contract. Used for migration scenarios where only new workstations need setup.

5B. Compliance & Taxation

RGPD / LOPDGDD
RGPD — Reglamento General de Protección de Datos (EU GDPR). LOPDGDD — Ley Orgánica de Protección de Datos y Garantía de Derechos Digitales (Spanish GDPR implementation). When enabled, adds data protection compliance documentation labour (+5 hours setup) and is noted in the proposal's compliance section.
NIS2
NIS2 Directive — EU cybersecurity directive for critical and essential entities. When enabled with "Critical Sector," Tier 1 is blocked (insufficient security). When enabled with "Important Sector," all tiers are allowed but SentinelOne EDR pricing is multiplied by 2.5x for enhanced detection coverage.
IVA Rate
IVA — Impuesto sobre el Valor Añadido (Spanish VAT). Three rates: 21% standard, 10% reduced (some services), Exempt (certain B2B services). Applied to all prices shown (setup + monthly). The PDF shows "IVA included" pricing separately.
IT Glue
Documentation platform for IT documentation. When forced on, adds IT Glue licensing costs to all tiers. Can be toggled from the admin panel's software section.

5C. Licensing & Sourcing

M365 Licenses
Microsoft 365 (formerly Office 365). Enter the number of Business Premium and Business Basic licenses needed. These are resold through SMGTEC — they carry cost and retail pricing from the sourcing DB and are included in all tiers' monthly recurring costs/revenue.
Dropsuite
Email backup and archiving solution. Licensed per mailbox. Resold through SMGTEC similarly to M365.
VoIP / 3CX
VoIP — Voice over IP phone system using 3CX platform. Enter the number of extensions needed. Resold license with cost/retail from sourcing DB.
+ Item Button
Each section header has a + Item button. Clicking it adds a custom line item to every tier's line-item override grid, keyed to that section (Infra / Compliance / Licensing). Used for one-off items not in the standard catalog.

5D. Custom Sourcing Injector & Line-Item Override Grid

Add from Catalog
Dropdown + "Add to Tier" button that lets you insert any item from the admin sourcing database into a specific tier's pricing. Items appear in that tier's override grid where you can override cost/retail.
Line-Item Grid
The table at the bottom showing Item, Cost (Wholesale), and Price (Retail) for every line item across all tiers. You can override any value by typing directly into the grid. Overrides persist until you click "Reset Items."
✕ Remove Button
Hover over any row in the line-item grid to reveal a red ✕ that removes that item from the tier. Removed items can be re-added via "Add from Catalog."

6 Right Column — Dashboard & Tiers

6A. Warning Banners

Minimum Billing
If total workstations W is between 1 and 9, a warning reminds that the minimum billing is 10 seats. The pricing still computes but with a service advisory.
NIS2 Block
When NIS2 is active and set to "Critical Sector," Tier 1 is disabled with a note that it does not meet minimum security requirements.
Warranty Warning
Shown when Expired Warranty is checked or a "Retain Existing Server" assessment is selected. Advises hardware refresh or warranty extension.

6B. Service Tiers

Tier 1: Data Protection Bare Bones Profile

Minimum viable protection. Includes Backblaze cloud backup, basic monitoring, and 2 hours/month maintenance. SLA: None (best effort). Best for: Very small businesses on a tight budget where basic data backup is the primary concern.

Tier 2: Active Perimeter Security Protected Setup

Adds FortiGate 60F firewall with UTM subscription, ESET antivirus, and 3 hours/month maintenance. SLA: 10% rebate on monthly fee per incident. Best for: SMBs needing a proper security perimeter with UTM (Unified Threat Management).

Tier 3: Fully Protected Centralization & Continuity

Full stack: Server (buy/retain/cloud), Datto Siris BDR, APC UPS, FortiGate, SentinelOne EDR, N-Central RMM, 5 hours/month maintenance. SLA: 15% rebate. Best for: Organizations requiring full infrastructure, disaster recovery, and maximum protection.

6C. Per-Tier Dashboard Metrics

One-Time Setup
Non-recurring costs and revenue for initial deployment: Charge (what the client pays), Cost (SMGTEC's wholesale), Profit/Margin (€ and %). Emerald = margin ≥ 40%, Red = below threshold. Also shows IVA-included total and 50% deposit due on signature.
Monthly Recurring
Ongoing monthly charges split into Y1 (Year 1, includes some intro pricing and setup costs like Backblaze seeding) and Y2+ (recurring steady state with full stack). Each shows revenue, cost, profit, and margin %. Below the blended margin, you'll see Services margin (excluding resold software licenses) — this is the number used for the approval threshold.
Year 1 Aggregate
Total revenue, cost, profit, and services margin for the first full year (setup + 12 months). Visual progress bar turns emerald ≥ 40%, red below. The blended margin (including software) is shown in smaller text below the bar.
✓ APPROVED / ! PENDING
Shown in each card header. Green = setup margin ≥ 40% AND services margin ≥ 40%. Red = one or both below threshold. The global approval badge at the top turns red if any enabled tier is pending.

6D. Compliance & Risk Summary

Deposit
50% of the setup fee due on contract signature. The remaining 50% is due on delivery and acceptance. Standard practice for hardware-heavy IT projects in Spain.
SLA Penalty
SLA — Service Level Agreement. Tier 1 has no SLA (best effort). Tier 2 penalises 10% of monthly fee per breach. Tier 3 penalises 15%. Shows as exposure per event.
Early Exit Penalty
If the client terminates before 12 months, they owe 50% of the remaining contract value. Shown in the compliance footer.

7 PDF Quote Output

Header
Company logo area with SMGTEC letterhead, proposal title, unique quote ID (auto-generated), and issue date.
Client Info Box
Client name, NIF/CIF, address, and contact details as entered in the input fields.
Tier Tables
Each enabled tier is shown with its own table: one-time setup breakdown, monthly recurring table (Year 1 vs Year 2), and Year 1 aggregate summary. Margin percentages are colour-coded green (≥ 40%) or red.
Services Margin Note
Each tier's monthly table shows the services margin (excluding resold software licenses like M365, VoIP, Dropsuite) with a note that the threshold is 40%.
Contract Terms
Standard terms box with gold border: hardware deposit terms, late payment penalty (1.5%/mo), minimum 12-month term, early termination (50% of remaining), SLA details, IVA rate used, and RGPD compliance status.
Approval Banner
Green banner with check mark if all tiers approved (services margin ≥ 40%), or red warning banner if any tier requires admin approval.
Footer
SMGTEC company details, NIF, address, quote number, page X of Y, and generation date — repeated on every page.
